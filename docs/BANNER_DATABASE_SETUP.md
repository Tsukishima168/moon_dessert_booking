# 公告與活動使用指南

> 2026-10-14 候選版。資料庫一律走核准的 migration；不要重跑舊版匿名計數 SQL 或插入測試活動。上線順序見 [上線與驗證](SHOP_PROMOTIONS_ROLLOUT.md)。

## 後台操作

`/admin/banners` 可新增／編輯標題、簡短說明、完整活動規則、優惠碼、按鈕文字與網址，並設定顯示方式、顏色、順序及台灣時間排程。新公告預設關閉，先預覽再啟用。

首頁公告位於介紹與商品目錄之間。多筆同時有效時，顯示優先順序最高的第一筆。首頁提供活動詳情視窗、複製優惠碼及自訂連結文字。內容是純文字並保留分行，不接受 HTML。

- 詳情寫活動日期、門檻、適用品項與限制；不應放內部開發訊息。
- 優惠碼必須先在優惠碼管理建立，填入公告不會自動新增折扣。
- 站內網址以 `/` 開頭，外部只接受 HTTPS 且不含帳密；拒絕反斜線與控制字元。
- 建議沿用深綠 `#1F3527` 與奶油白 `#F5F0E8`。系統會檢查文字／背景對比至少 4.5。
- 圖文橫幅用既有 HTTPS 圖片，桌機小圖、手機隱藏圖；不是全寬主視覺或圖片上傳系統。
- 客人關閉後會記住，公告更新後可再次顯示；瀏覽器禁止儲存時仍可操作，但下次訪問不保證記住。

## 統計

實際可見的公告才記曝光；開詳情、複製碼或連結互動記一次。同次曝光的重複互動不重算，頁面所有未顯示公告不會一起灌數。

數字僅供活動觀察，**不是訂單、付款或成交數**。新資料經受保護的伺服器端 RPC 去重與限流；舊 `increment_banner_views/clicks` 的匿名執行權限已在新 migration 撤銷，勿重新授權。

事件使用隨機曝光識別碼；限流只存按分鐘生成的 HMAC，不存原始 IP、Email、會員 ID。舊限流鍵與曝光去重紀錄於後續有效統計請求中清理，分別為一小時／三十日以前的紀錄；沒有背景流量時不保證立即移除。站內隱私頁已同步說明。

統計失敗不阻止看公告、開詳情或前往商品。
