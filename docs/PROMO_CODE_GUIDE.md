# 優惠碼與會員活動使用指南

> 候選功能：須先核准並套用 `20261013230000_shop_promotions.sql`，再部署對應程式。文件不表示正式環境已啟用；詳見 [上線與驗證](SHOP_PROMOTIONS_ROLLOUT.md)。

## 店主設定

到 `/admin/promo-codes` 新增活動，先確認後台登入。可設定定額折抵、減少商品金額的百分比、商品低消、總量、開始／結束時間、會員限定與每人次數。時間欄位均為台灣時間。

- `12%` 表示減去商品金額的 12%，也就是 **8.8 折**；定額折抵填新台幣整數，百分比最多兩位小數。
- 優惠只折抵商品，不折運費；同一筆訂單使用一個活動碼。最後金額會由伺服器依實際商品重新計算。
- 留空總量表示不限制活動總次數；留空截止日期表示沒有期限。會員限定開啟時，每人預設一次，也可設定多次或留空不限。
- 已建立的代碼在介面保留原名。有使用歷史的代碼也會由資料庫阻止改名；新活動請另建代碼。
- 已使用活動請停用，保留歷史。只有沒有使用紀錄的活動能刪除。
- 儲存欄位與使用量分離；不得用 Table Editor 或 SQL 重置 `used_count`，否則會破壞名額與帳本一致性。

頁面試算只是驗算工具，不會建立訂單，也不會自動建立／發布範例活動。

## 客人使用

一般活動碼在結帳頁輸入；會員限定活動須先登入。Shop `/account?tab=offers` 的「我的優惠」列出目前會員活動、低消、期限與自己的使用量，可複製後在結帳貼上。

這是**所有登入會員適用的活動碼**，不是每人獨立發券、領券或首購資格系統。會員優惠尚未接到 Passport 的券匣；其他站不在本次改動範圍。

最低消費按商品小計，結帳試算與正式建單均重新檢查登入、期限、總量與每人名額。活動條件改變或名額用完時，不會沿用舊試算放行。

## 使用量的含義

建單前會原子占用名額，避免同時結帳超額；包含待付款訂單，**使用量不是付款筆數**。只有確認資料庫交易已回滾的失敗會釋放；結果不明時保留占用，避免已成立訂單重用名額。

取消訂單不會自動恢復優惠。需要先核對訂單與帳本，由另行授權的流程處理；此版本沒有提供任意重置或補回名額按鈕。每人次數按登入帳號計算，不等同真人身分去重。

## 與公告搭配

先建立優惠，再到 `/admin/banners` 填標題、簡述、完整規則、同一活動碼與按鈕。可填 `/account?tab=offers` 引導會員查看，或 `/#menu-section` 返回商品。

正式活動文案與折扣由店主決定。不要把本機展示代碼或虛構活動直接當成正式優惠。
